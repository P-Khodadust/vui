vui

Tiny shadcn/ui-style components for pure PHP and Laravel. No runtime package: a small CLI copies source files into your project, and you carry only what you added.

Core 1,216 B0 dependencies0 KB JS by defaultRTL firstTailwind v4

Install

php vui init
php vui add button card dialog

Pure PHP

<?php
require __DIR__ . '/ui/ui.php';

echo card(raw(
    card_header(raw(card_title('Hello') . card_description('From plain PHP.'))) .
    card_content(raw(button('Save')))
));

Laravel Blade

<x-ui.card>
    <x-ui.card.header>
        <x-ui.card.title>Hello</x-ui.card.title>
        <x-ui.card.description>From Blade.</x-ui.card.description>
    </x-ui.card.header>
    <x-ui.card.content><x-ui.button>Save</x-ui.button></x-ui.card.content>
</x-ui.card>
