Components to add

0 bytes for 0 components and everything they need.

Run this in your project
php vui init
php vui add

Counts PHP, Blade, CSS and JavaScript. Pure PHP projects skip the Blade files, so they carry less.

Needs PHP 8.1 and Tailwind v4, nothing from Composer. 9 of the 54 components use JavaScript, at most 2 KB per file and no libraries.

Write PHP or Blade

The Blade wrappers call the same PHP functions, so both render the same HTML.

Pure PHP
<?php
require __DIR__ . '/ui/ui.php';

echo card(raw(
    card_header(raw(card_title('Hello') . card_description('From plain PHP.'))) .
    card_content(raw(button('Save')))
));
Laravel Blade
<x-ui.card>
    <x-ui.card.header>
        <x-ui.card.title>Hello</x-ui.card.title>
        <x-ui.card.description>From Blade.</x-ui.card.description>
    </x-ui.card.header>
    <x-ui.card.content><x-ui.button>Save</x-ui.button></x-ui.card.content>
</x-ui.card>
